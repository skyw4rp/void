# VOID — Game Pillars

**Canonical north star.** When a feature, asset, or system does not serve these pillars, it does not ship.

**Depth elsewhere:** [VOID_DESIGN_PHILOSOPHY.md](VOID_DESIGN_PHILOSOPHY.md) (feel gate) · [VOID_GLADIATOR_LOOP.md](VOID_GLADIATOR_LOOP.md) · [VOID_GLADIATOR_IDENTITY.md](VOID_GLADIATOR_IDENTITY.md) · [VOID_RETURN_LOOP.md](VOID_RETURN_LOOP.md) · [PROTOTYPE.md](PROTOTYPE.md) (current build)

## 1. Core fantasy

**Player fantasy:** *“I am a gladiator living inside a brutalist cosmic arena system.”*

Not a savior. Not a tourist. A **tenant** of infrastructure suspended over an indifferent void — fighting because the system demands it, preparing because the chamber is the only place that is yours.

**Session loop:**

```
Prepare → Fight → Return → Progress → (repeat)
```

| Phase | Meaning |
|-------|---------|
| **Prepare** | Loadout, chamber, identity — who you are this queue |
| **Fight** | Arena FPS duel — void and opponent both threaten |
| **Return** | Emotional landing — room answers win or loss |
| **Progress** | Resonance, Fragments, Prestige — history, not power creep |

---

## 2. Combat pillar

**Arena FPS.** Fast. Physical. Readable. **Quake DNA.**

| Tenet | Practice |
|-------|----------|
| Speed with weight | Momentum and friction, not float |
| Aim clarity | Stable look; effects never fight crosshair |
| Spatial rhythm | Movement defends; positioning wins |
| Readable weapons | Silhouette + audio tell threat |

**Movement = survival.** Dodges, strafes, edge awareness, and void fear are one system — not cosmetics on a cover shooter.

**Win conditions:** Break the opponent or **ring them into the void** — both must read clearly.

---

## 3. Emotional pillar

Emotion lives in **space and pacing**, not congratulation screens.

| Outcome | Feel | Duration |
|---------|------|----------|
| **Victory** | Clarity, space, breathing | **Longer** — calm lingers in chamber and Observatory |
| **Defeat** | Pressure, weight | **Shorter** — acknowledge, then recover |

**Rules:** No punishment loops. No shame UI. Defeat returns agency fast; victory does not become a carnival.

## 4. Identity pillar

Identity is **symbolic**, not class-based.

| Source | Role |
|--------|------|
| **Helmet** | Recognition, prestige, memory |
| **Armor** | Role silhouette (light / medium / heavy) |
| **History** | What you have endured |
| **Chamber** | Private archive — trophies, etchings, displays |
| **Victories** | Proof in the system’s ledger |

**No classes. No heroes.** Opponents read **look and rhythm**, not talent trees.

→ [VOID_GLADIATOR_IDENTITY.md](VOID_GLADIATOR_IDENTITY.md) · [VOID_GLADIATOR_LOADOUT.md](VOID_GLADIATOR_LOADOUT.md)

## 5. Space pillar

The player **lives in the chamber** between matches — walkable, brutalist, intimate.

| Tenet | Practice |
|-------|----------|
| **No menu-first** | Terminal, racks, pedestals — diegetic |
| **World = physical** | Prep, queue, return, transitions in-body |
| **Void at the edge** | Observatory and deck perimeter — scale over UI |

Queue in chamber. Depart through **short ritual transit** — not loading-screen fantasy.

→ [VOID_GLADIATOR_CHAMBER.md](VOID_GLADIATOR_CHAMBER.md) · [VOID_ARENA_TRANSITIONS.md](VOID_ARENA_TRANSITIONS.md)

## 6. Progression pillar

Progression is **gladiator history**, not endless stat levels.

| Resource | Job |
|----------|-----|
| **Resonance** | Breadth — unlock loadout options |
| **Fragments** | Intensity — wins, consumables, armor |
| **Prestige** | Reputation — cosmetics, helmets, chamber crest |

**Unlocks:** loadout pieces, visual identity, **chamber objects** — not +1% spam.

→ [VOID_GLADIATOR_LOOP.md](VOID_GLADIATOR_LOOP.md)

---

## 7. Risk / reward pillar

**High risk. High reward. Fast recovery.**

| Risk | Reward |
|------|--------|
| Void ring-out, exposure, shield break | Round win, resources, room unlocks |
| Ranked Prestige swing | Recognition — never paid power |

Loss still pays **reduced** Resonance — you remain in the system. Next queue is always reachable without energy timers or gear repair tax.

---

## 8. Visual pillar

**Brutalist. Void. Oppressive.** Architecture **dominates** the player.

| Prioritize | Reject |
|------------|--------|
| Silhouette, contrast, fog depth | Clean sci-fi panels, bright saturation |
| Oxidized metal, wet concrete | Cartoon styling |
| Infinite drop, distant megastructure | Decorative darkness without volume |

Combat reads at speed; the void reads at rest. Enemies are readable armored threats — not noisy glow blobs.

## 9. Anti-pillars

If a proposal sounds like one of these, **stop**.

| Anti-pillar | Why it fails VOID |
|-------------|-------------------|
| **Hero shooter** | Chosen-one fantasy, ability clutter, team-role noise |
| **RPG stat bloat** | +1% grids, levels, talent trees — identity becomes spreadsheet |
| **Menu simulator** | Hub as UI stack, teleport queue, loot popups |
| **MMO scope** | Open world, factions, economies, social layers before core duel works |
| **Pay-to-win** | Combat stats for money — breaks risk/reward and arena fairness |

```
FANTASY ── gladiator in cosmic arena system
    │
    ├── COMBAT ──────── fast · physical · Quake · void + duel
    ├── EMOTION ─────── victory clarity / defeat weight · fast recovery
    ├── IDENTITY ──── helmet · armor · chamber · history
    ├── SPACE ───────── physical chamber · ritual transit
    ├── PROGRESSION ─── resonance · fragments · prestige
    ├── RISK/REWARD ─── high stakes · always re-queue
    └── VISUAL ──────── brutalist void · architecture dominates

ANTI: hero shooter · RPG bloat · menu sim · MMO · P2W
```
