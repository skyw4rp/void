# Roadmap

High-level phases for VOID / Neon Catacombs evolution.

---

## Phase 0 — Prototype (Current)

- [x] 1v1 bridge arena, FPS movement
- [x] Weapons + knockback + shield/health
- [x] Void and kill scoring, countdown
- [x] VOID_GORE void death cinematic
- [x] Void atmosphere + observers
- [x] Design documentation structure
- [ ] Real audio implementation
- [ ] Playtest balance pass

---

## Phase 1 — Vertical Slice

- One polished arena with full audio
- Single enemy type + full player kit
- Marketing capture quality (trailer shots)
- Options: void style, accessibility (motion, photosensitivity)
- Basic main menu and pause

---

## Phase 2 — Demo

- 2–3 arenas with distinct void layouts
- Progression or match series mode
- Environmental lore beats (no exposition dump)
- Performance pass (stable 60fps target TBD)
- Controller support polish

---

## Phase 3 — Steam Page

- Capsule art, screenshots, short description emphasizing **void horror + arena combat**
- Store tags: horror, FPS, action, indie
- Demo build uploaded
- Wishlist campaign start

---

## Phase 4 — Polish

- Full SFX/music pass
- UI/UX pass
- Localization (if scope allows)
- Achievements / stats (optional)
- Release candidate

---

## Risks

| Risk | Mitigation |
|------|------------|
| Horror and fairness conflict | Keep pit edges readable; playtest knockback |
| Scope creep on lore | Mystery rules doc; cut codex |
| VFX cost | Lifetimes, pool nodes, limit simultaneous chunks |
| Multiplayer desire | Defer; nail 1v1 feel first |
